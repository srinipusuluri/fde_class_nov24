2. The whole architecture

3. What each layer does

Session

Claude Code main session

Takes your request, holds the permission mode, and hands the review to the subagent so the file reading stays out of your main conversation.

Memory

CLAUDE.md

Repo facts a new session needs: the commands and how the Apex code is layered. It is context, not behavior.

Agent

sf-code-reviewer

A role with its own prompt and a limited tool list. It is the worker that runs the review in a separate context. It is told to write only the report.

Skill

sf-code-review

The reusable know-how: steps, severity levels, report layout, and the checklist. It also works without the agent by typing /sf-code-review.

Script

complexity.py

Gives measured numbers, so complexity is not guessed. It is a regex heuristic, so the agent confirms flagged methods by reading them.

Output

HTML report

Single offline file with inline CSS and light and dark themes. It is a local file and is not published.

4. Runtime sequence

  1. You ask for a review, or Claude sees the agent description matches and delegates.
  2. The subagent starts with a clean context and loads the skill and checklist.
  3. Glob lists the in-scope files, then complexity.py returns the numbers.
  4. It reads every file in full, tests included, and greps for callers to check context.
  5. It scores the 12 categories, writes findings with file:line evidence, and computes a grade.
  6. It writes the single HTML report, then replies with the path, grade, and top three blockers.
